# Library Database Final Project

## Purpose

Models a library network with publishers, books, branches, borrowers, and lending relationships.

## What it demonstrates

- Entity modeling for a multi-branch library
- Constraints and referential relationships
- DDL, DML, and reporting queries

## Run

Execute [`library-database-final-project.sql`](../../sql/library-database-final-project.sql) in MySQL Workbench or the MySQL CLI. The script creates the `LibraryDB` sample database.
