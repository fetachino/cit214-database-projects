# Consulting Database

## Purpose

A relational model for consultants, clients, projects, assignments, and billing-oriented business data.

## What it demonstrates

- Translating a small business domain into related tables
- Defining identifiers and required attributes
- Loading sample records and querying across relationships

## Run

Execute [`consulting-database.sql`](../../sql/consulting-database.sql) in MySQL Workbench or the MySQL CLI. The script uses sample coursework data.
