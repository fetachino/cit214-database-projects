# MySQL Premiere Exercises

## Purpose

A set of focused MySQL exercises using a small retail schema to practice filtering, joins, aggregation, and business-oriented reporting.

## What it demonstrates

- Writing readable SELECT statements
- Joining related tables
- Grouping and aggregating business measures
- Validating query results against sample data

## Run

Execute [`mysql-premiere-exercises.sql`](../../sql/mysql-premiere-exercises.sql) in MySQL Workbench or the MySQL CLI after reviewing the database and table setup statements.
