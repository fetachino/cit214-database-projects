# Apartment Rental Database

## Purpose

A relational apartment-rental schema covering buildings, employers, tenants, and rental relationships.

## What it demonstrates

- Database creation and table lifecycle management
- Primary keys, foreign keys, and required attributes
- Multi-table joins and query-based reporting

## Run

Execute [`assignment-2-apartment-rental.sql`](../../sql/assignment-2-apartment-rental.sql) in MySQL Workbench or the MySQL CLI. Review the DDL before running because the script creates and drops classroom databases/tables.
