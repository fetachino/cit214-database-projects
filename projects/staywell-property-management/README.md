# StayWell Property Management Database

## Purpose

Represents properties, owners, tenants, leases, and maintenance-oriented data for a property-management workflow.

## What it demonstrates

- Relational modeling around business operations
- Data loading and integrity constraints
- Queries that support operational reporting

## Run

Execute [`staywell-property-management.sql`](../../sql/staywell-property-management.sql) in MySQL Workbench or the MySQL CLI. The records are sample coursework data.
