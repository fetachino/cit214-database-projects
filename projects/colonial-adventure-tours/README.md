# Colonial Adventure Tours Database

## Purpose

Models adventure trips, guides, customers, reservations, and seasonal tour reporting.

## What it demonstrates

- Translating a business domain into relational tables
- Loading sample records and validating relationships
- Filtering, joining, and aggregating tour data

## Run

Execute [`colonial-adventure-tours.sql`](../../sql/colonial-adventure-tours.sql) in MySQL Workbench or the MySQL CLI. The included records are textbook-style sample data.
