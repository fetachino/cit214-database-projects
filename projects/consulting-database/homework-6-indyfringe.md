# Homework 6 — IndyFringe Event Database

This CIT 21400 exercise designs a normalized event-brochure database with `EVENT`, `LOCATION`, and `PERFORMANCE`/`SHOW_TIME` entities. Separating show details from individual scheduled performances prevents duplication and supports venue- and time-based queries.

## Skills demonstrated

ER diagrams, one-to-many relationships, surrogate keys, foreign keys, normalization, and schema trade-off analysis.
